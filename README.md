# Mo Portfolio — Feeling Responsive style

A Jekyll portfolio starter rebuilt around the structure documented by the Feeling Responsive theme: YAML navigation, frontpage widgets, page layouts, right sidebar, project collection, and configurable social links.

## Run locally

```bash
bundle exec jekyll serve
```

## GitHub Pages

Push the repository to GitHub and enable Pages from the `main` branch root. If your repository is not `username.github.io`, set `baseurl` in `_config.yml` to the repository name.

## Customize

- `_config.yml` — site title, URL, base URL
- `_data/navigation.yml` — navigation
- `_data/socialmedia.yml` — social links
- `index.html` — homepage copy/widgets
- `pages/about.md`, `pages/contact.md` — personal pages
- `_projects/` — portfolio case studies
- `assets/css/style.css` — colors and styling

The visual/structural inspiration follows Feeling Responsive's documented frontpage widgets, page/sidebar formats, configurable navigation and responsive layout. See the original project: https://github.com/Phlow/feeling-responsive
