# Mo. — Feeling Responsive Portfolio

Overlay files for the existing `mosyrf.github.io` repository.

Copy these files/folders into the root of your existing repository and overwrite files with the same path. Your existing `Gemfile`, `Gemfile.lock`, and `.github/workflows/pages.yml` can stay as they are.

The update keeps the existing project content while adding a functional `/projects/` index, a closer Feeling Responsive-style layout, responsive project cards, a project-case-study visual system, and corrected email actions.
